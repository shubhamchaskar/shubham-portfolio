# Shubham Chaskar - Portfolio Website

This is a personal portfolio website showcasing my CV and Power BI dashboards.

## Features
- About Me
- Work Experience
- Skills
- Power BI Project Snapshots
- Education
- Contact Information

## How to Use
1. Clone or download this repository.
2. Place your Power BI dashboard images inside the `images/` folder.
3. Update `index.html` with your own details if needed.
4. Push to GitHub and enable GitHub Pages in repo settings.

Your site will be live at:
```
https://<yourusername>.github.io/shubham-portfolio/
```
